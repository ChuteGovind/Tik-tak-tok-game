🎮 How to Play
Open the game in your browser.

Player 1 starts with X.

Player 2 plays with O.

Players take turns selecting an empty box.

The first player to get three symbols in a row wins.

A row can be:

Horizontal
Vertical
Diagonal
If all boxes are filled without a winner, the game ends in a draw.

Use the reset/new game button to play again.

▶️ Run Locally
No installation or additional dependencies are required.

Clone the repository:

git clone https://github.com/ChuteGovind/Tik-Tok.git
Move into the project folder:

cd Tik-Tok
Then open index.html in your browser.

You can also simply download the repository and open index.html.
